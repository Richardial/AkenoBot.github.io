## 1. Introduction

This Privacy Policy explains how "Akeno" collects, processes, stores, and uses data when operating on Opera Discord server.

The Bot is designed to help server administrators detect phishing attempts by analyzing deleted messages available through a designated logging channel and taking moderation actions when malicious content is identified.

## 2. Data We Collect

The Bot may process the following information as necessary to provide its functionality:
- Message content made available through the server's logging channel.
- Discord user IDs and server IDs associated with relevant messages.
- Message metadata required for phishing detection and moderation.
- Information necessary to execute moderation actions, such as banning a user.

The Bot does not intentionally collect information unrelated to its stated functionality.

## 3. How We Use Data

Data is processed exclusively for the following purposes:

- Detecting potential phishing messages.
- Identifying users associated with suspected phishing activity.
- Enforcing server moderation rules, including banning users when appropriate.
- Maintaining the Bot's security and operational reliability.

## 4. Data Storage and Retention

The Bot does not store any user information in databases or other persistent storage systems. It temporarily processes the original message content to compare it against common phishing messages and determine whether similarities exist.
If a message is identified as potentially containing phishing content, the Bot uses information provided by Discord through the Server Members Intent to identify the relevant user and execute the ban action.
User information and message content are not stored in any database. The processing is limited to the detection of potential phishing attempts and the execution of the corresponding moderation action.

## 5. Data Sharing
We do not sell Discord user data or share it for advertising purposes. Any service providers involved in processing data must be disclosed where applicable.

## 6. Data Security
We take reasonable measures to protect processed data against unauthorized access, disclosure, alteration, or destruction.
However, no system can guarantee absolute security.


## 7. Changes to This Policy
This Privacy Policy may be updated as Akeno's functionality or data practices change. The latest version will remain available at the public URL associated with Akeno.
